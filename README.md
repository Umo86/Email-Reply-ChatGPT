# Email-Reply-ChatGPT

A single-page prototype for setting up event email agents. The walkthrough covers agent name, inbox details, a text-based knowledge base, and a local question test. It also includes common-question tracking, unanswered-question suggestions, knowledge clarifications, and heuristic conflict flags.

## Run

Open `index.html` in a modern browser. Data is stored in that browser's local storage. No server or build step is required.

## Current scope

This is a front-end prototype. Microsoft 365 mailbox authorization, live email reading and Outlook draft creation, hosted persistence, PDF/Word file extraction, and AI-generated replies are not connected. The knowledge test searches uploaded text locally. Conflict flags are suggestions for human review.
